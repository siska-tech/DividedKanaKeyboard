# [#09] LEDステータス表示（WS2812B）

- **優先度:** P3
- **状態:** ✅ Done（2026-06-09 実機）
- **依存:** #01, #06
- **関連設計:** 要件 FR-6 / §2.1（WS2812B = GP28, 各半身2個）

## 目的
状態が見えず操作状況が分からない問題を解消。役割（マスタ/スレーブ）と
シフト状態（センター/濁音/半濁音/小書き）をLEDで可視化する。

## 実装（done）
- [x] WS2812B を **PIO0 + DMA_CH0** で駆動（embassy-rp `PioWs2812`, GP28, N=2, GRB）
- [x] LED色: シフトなし=役割色（マスタ緑/スレーブ青）、シフト中=シフト色
  （センター=シアン / 濁音=赤 / 半濁音=黄 / 小書き=青）
- [x] **両LED同色**（1個しか実装/視認できなくてもシフトが見える）
- [x] **短時間ラッチ**（60ms保持）で一瞬の濁音同時押しも視認可能
- [x] engine に `display_shifts()`（held＋pending中のシフトキー）追加
      → シフトキーを押した瞬間に点灯（連続シフト確定前でも反映）
- [x] **スレーブ側もシフト表示**: マスタが状態をUART Statusフレームで送信
      （split.rs `Frame::Status`、変化時＋約0.5sハートビート）

## 既知の調整ポイント
- 色割当・輝度・ラッチ時間・更新間隔(20ms)は `main.rs status_colors/shift_color/LEDループ` で調整可。
- スレーブのシフト表示はUART経由のため、マスタのみが厳密にリアルタイム。

## 参考
- 役割は `USB_CONFIGURED`（#06/#05）。シフトは engine（マスタ）が `HELD_SHIFTS` に publish。
