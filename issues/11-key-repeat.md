# [#11] キーリピート機能（長押しでBS/←/→等を連続送出）

- **優先度:** P2
- **状態:** ✅ Done（2026-06-10）engine実装＋コア46テスト緑。BS/←/→（単打面）＋編集モード制御キーをカバー。実機検証済。
- **依存:** #03（engine）, #10（編集モード/制御キー送出）
- **関連設計:** 要件 FR-4.2（制御キー送出）, FR-7.1（パラメータ調整）, NFR-1（レイテンシ）

## 目的
**キーを押し続けている間、一定間隔でそのキーを連続送出する**（オートリピート）。
特に編集系の制御キー（**BackSpace / ←（左矢印）/ →（右矢印）**、必要に応じて ↑↓/Del 等）で、
長押しによる連続移動・連続削除を可能にし、編集モード（#10）の実用性を高める。

## スコープ（やること）
- [x] engine にリピート状態機械を追加：押下継続キーに対し
      **初回ディレイ → 以降リピート間隔**で繰り返しイベントを生成（`Repeat`/`tick`）
- [x] リピート対象キーの定義（`REPEAT_USAGES`: BS/Del/←→↑↓。修飾なし単一キーのみ）
- [x] **2系統で発火**：
      ① **単打面**の制御キー（u=BS / t=← / y=→）= `pending` 窓確定（tick timeout）後に開始
      ② **編集モード**の制御キー（mode1 o=Del, mode2 j=→/m=← 等）= press 即時 emit 後に開始
- [x] かな同時打鍵判定との両立：リピート開始は
      「**窓確定で押下継続中の単打**」または「**編集モードで解決された制御キー**」に限定。
      連続シフト中の即時 emit／コンボ／pend3 経由は対象外（修飾付き・選択キーは `modifiers!=0` で除外）
- [x] パラメータをFR-7.1準拠で調整可能に（`set_repeat(delay, interval)`。既定 300ms / 40ms）
- [x] 解放（キーアップ）で即時リピート停止＋モード終了でも停止

## やらないこと
- かな文字そのもののリピート（薙刀式の通常打鍵はリピート対象外。制御/編集キーに限定）
- ホストOS側のリピート設定への依存（ファーム側で完結させる。OS差を吸収）

## 受入条件（Done の定義）
- [x] BS 長押しで連続削除（単打面 u=BS。`repeat_base_bs` テスト）
- [x] ←/→ 長押しでカーソルが連続移動（単打面 t=← / y=→、編集モード j/m。`repeat_base_left` 等）
- [x] 単打（即タップ）・同時打鍵（濁音/拗音/コンボ）が**誤ってリピートしない**（回帰: 既存38＋誤爆テスト緑）
- [x] 初回ディレイ・間隔がパラメータで変更できる（FR-7.1: `set_repeat`）
- [x] 実機でカーソル移動／削除のリピートが体感良好（NFR-1）✅ 確認（2026-06-10）

## 実装メモ / 参照
- 実装: [naginata-core/src/engine.rs](../naginata-core/src/engine.rs)。**ファーム変更不要**
  （engine_task が既に 5ms 周期で `tick` を回しており、そのまま駆動される）。
- `Repeat{ sc, action, next_at }` を `Engine` に追加。開始する2経路:
  - **単打面**: `tick` の窓超過 `flush_pending` が返す (sc, action) が `is_repeatable` なら開始
    （= 窓確定時点でキーは押下継続中。`release` 経由の確定は押下解放なので開始しない）。
  - **編集モード**: press で `mode_lookup` した action が `is_repeatable` なら開始。
- `tick(now)` 先頭で期限到達なら1回 emit → `next_at = now + interval`（取りこぼし時もバースト無し）。
- `is_repeatable`: `Action::Keys([KeyPress{usage, modifiers:0}])` かつ usage ∈ `REPEAT_USAGES`
  （BS/Del/←→↑↓）。Ctrl系（コピー/undo）・選択（S-*）は修飾付きで除外。
- `release(sc)` で `repeat.sc==sc` 解放／モード終了時にクリア。
- **配列について**: BS/←/→ は単打面（u/t/y, layout `when:[]` の `keys`）に既存。編集モードに BS 単独は
  元仕様通り無し（不要・ユーザ確認済）。リピートは単打面側で機能する。
- 設定値（delay/interval, 対象キー集合）は #12（PCカスタマイズ）の対象パラメータにも含める。
